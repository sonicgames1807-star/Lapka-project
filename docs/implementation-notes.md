# Реализация и статус

## Стек

Статические HTML/CSS/JavaScript без сборщика; localStorage для текстовых данных и IndexedDB для локальных вложений. Подходит для быстрого запускаемого прототипа без ключей и серверной инфраструктуры.

## Модель данных (локальная, демонстрационная)

- `pets`: питомец, вид, порода, дата рождения, заметка.
- `events`: заголовок, дата, питомец, заметка, статус, интервал повтора.
- `foodEntries`: дата, питомец, продукт/корм, заметка.
- `documents` и `photos`: метаданные плюс локальный blob в IndexedDB.
- `settings`: завершение знакомства, город, настройки отображения и обнаружения.
- `communityState`: локальные состояния запросов/блокировок/жалоб; демонстрационные карточки фиксированы в клиенте.

## API и внешние подключения

Внешние API отсутствуют. Не подключены геокодер, карты, каталог заведений, backend, аккаунты, чат, ветеринарная служба, push, аналитика и база знаний. Интерфейс не должен восприниматься как факт подключения.

## Проверки

`tests/smoke.cjs` проверяет onboarding без геолокации (разрешение не запрашивается), создание питомца, события и дневниковую запись, предостережение для примера «колбаса» и состояние неизвестного продукта, локальные состояния сообщества, приватность по умолчанию, локальное сохранение/скачивание файла, маркировку демо-чата врача и мобильную навигацию. Последний прогон: PASS, без ошибок страницы.

## Изображения и источники

Внешние изображения не загружены, лицензированные стоковые изображения не используются. Карточки используют встроенные CSS-иллюстрации/символы. Медицинские и породные статьи требуют источников и профессиональной проверки; сейчас контент явно маркируется как черновой демо-материал.
