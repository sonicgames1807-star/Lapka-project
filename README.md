# Лапка

Адаптивное русскоязычное приложение для личных профилей питомцев, ухода и справочной информации. Пустой старт — никаких подставных питомцев или пользователей. Приложение можно установить как PWA после размещения на HTTPS-хостинге.

## Запуск

```bash
python3 -m http.server 4173
```

Откройте `http://localhost:4173`. Для установки PWA и работы service worker нужен HTTPS или `localhost`.

## Обновления

- Профиль каждой собаки поддерживает собственное фото: загрузка, предпросмотр, замена и удаление. Фото сохраняется локально в IndexedDB.
- Сообщество больше не содержит вымышленных карточек. Пустое состояние объясняет, что для реальных участников нужен сервер и согласие пользователей.
- Раздел продуктов содержит **67 курируемых карточек**: опасные продукты, продукты с ограничениями и условно допустимые лакомства. Каждая карточка включает объяснение, рекомендацию по осторожности, ссылку на источник и дату проверки.
- Неизвестный продукт не объявляется безопасным. В базе нет выдуманных 5 000 оценок: для этого нужна ветеринарно проверенная база данных. Как расширять справочник безопасно, см. `docs/public-launch-checklist.md`.
- В чате врача можно выбрать проблему и заполнить готовые вопросы. Приложение собирает сообщение, которое можно скопировать; оно не отправляется и не имитирует ответ врача.
- Стартовый профиль пустой. При обновлении локальных данных прежние тестовые записи удаляются, пользовательские записи без метки демо сохраняются.
- Адаптивный интерфейс, PWA-манифест, офлайн-кэш оболочки приложения.

## Честные ограничения

Эта сборка **ещё не является публичным сетевым сервисом**: она не развёрнута в интернете, аккаунтов и серверной синхронизации нет. Профили, изображения, таймлайн, документы и заметки хранятся в браузере пользователя. Публичная регистрация, реальные личные сообщения, каталог мест, серверный чат врача, геокодирование и push-уведомления не подключены. Переключатель видимости не публикует данные без backend.

Не используйте приложение как замену врачу. Пищевые карточки — справочный стартовый набор, не полная база токсикологии и не индивидуальная оценка риска. Для публичного релиза выполните шаги в `docs/public-launch-checklist.md`.

## Проверки и документы

- `tests/smoke.cjs` — проверка пустого старта, фото питомца, поиска по продуктам, отсутствия фиктивных участников, анкеты врача и мобильной навигации.
- `food-data.js` — содержимое справочника и проверяемые источники.
- `docs/implementation-notes.md` — модель данных, источники, результаты тестов и ограничения.
- `docs/public-launch-checklist.md` — что нужно для реального публичного запуска.
- `docs/lapka_prompt_15000_requirements.txt` и `docs/backlog-15000.md` — полное исходное задание и все 15 000 строк требований с постоянными ID. Файл требований не означает, что каждый пункт реализован.
