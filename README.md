# Лапка — интерактивный прототип

Русскоязычное локальное веб-приложение для владельцев питомцев. Работает без сборки и внешних API: откройте `index.html` или запустите локальный сервер.

## Быстрый запуск

```bash
python3 -m http.server 4173
```

Затем откройте `http://localhost:4173`.

## Что работает

- Первичный экран знакомства, продолжение без геолокации и явный отдельный запрос разрешения.
- Локальные профили нескольких питомцев, переключение, редактирование и удаление.
- Таймлайн, создание/редактирование/завершение/удаление событий, повтор через 30 дней.
- Дневник питания и проверка продукта с честной демо-базой (в ней только пример «колбаса»).
- Демонстрационные экраны сообщества, запросов на общение, чата владельцев, жалоб и блокировки; данные не отправляются другим людям.
- Чат с врачом ясно помечен как неподключённая демо-заглушка.
- Архив документов и галерея с файлами, которые остаются в локальном хранилище браузера (IndexedDB).
- База знаний, петфрендли-места, шаблоны, настройки приватности, JSON-экспорт и сброс локальных данных.
- Основные данные хранятся только в браузере пользователя (localStorage/IndexedDB); сервер, аккаунты, синхронизация, уведомления и реальные интеграции не подключены.

## Ключевые допущения и ограничения

- Это запускаемый фронтенд-прототип, не production-сервис: в нём нет backend, настоящей регистрации, серверной авторизации, реальных врачей, каталога мест, геокодирования, push-уведомлений и модерации.
- Демо-профили сообщества и места вымышлены и помечены. Нельзя использовать их для реальных встреч или навигации.
- Переключатели приватности демонстрируют локальное UX-состояние; реальная серверная защита появится только после реализации API и проверки доступа.
- Проверка еды — не ветеринарный источник: единственная запись о колбасе внесена как осторожный демонстрационный пример из исходного задания. Не является диагнозом или рекомендацией.
- Статьи — незавершённые карточки контента; до публикации нужны ветеринарная редактура, проверяемые источники и даты актуальности.
- Фотографии пользователя не включены в стартовые данные; файлы, добавленные в этой версии, хранятся локально в текущем браузере.
- Полный исходный текст задания и 15 000 строк матрицы требований сохранены в `docs/`. Их наличие не означает, что каждый пункт реализован.
